# Facebook Sent Request Auto-Canceler (Chrome Extension)

একটি সিম্পল এবং পাওয়ারফুল ক্রোম এক্সটেনশন যা আপনার ফেসবুক থেকে পাঠানো পেন্ডিং ফ্রেন্ড রিকোয়েস্টগুলো অটোমেটিকলি ক্যান্সেল করে দিবে। এটি মূলত ডেভেলপার কনসোলে বারবার কোড পেস্ট করার ঝামেলা এড়াতে এবং ইউজার ফ্রেন্ডলি ইন্টারফেস দেওয়ার জন্য তৈরি করা হয়েছে।

## ✨ Features
- **Auto Cancel:** এক ক্লিকেই একের পর এক রিকোয়েস্ট ক্যান্সেল করা শুরু করে।
- **Real-time Counter:** কতগুলো রিকোয়েস্ট সফলভাবে ক্যান্সেল হয়েছে তা লাইভ দেখা যায়।
- **Start & Stop Control:** যেকোনো সময় কাজ শুরু বা বন্ধ করার সুবিধা।
- **Clear Counter:** কাউন্টার রিসেট করার অপশন।
- **Safe Interval:** ফেসবুক অ্যাকাউন্টের নিরাপত্তা নিশ্চিত করতে নির্দিষ্ট সময় বিরতি দিয়ে কাজ করে।

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Chrome Extension API (Manifest V3)

## 🚀 How to Install

১. **ফাইলগুলো ডাউনলোড করুন:** এই রিপোজিটরি ক্লোন করুন অথবা `manifest.json`, `popup.html`, এবং `popup.js` ফাইলগুলো একটি ফোল্ডারে সেভ করুন।
২. **ব্রাউজার ওপেন করুন:** Google Chrome বা যেকোনো Chromium ব্রাউজার (Edge, Brave) ওপেন করুন।
৩. **এক্সটেনশন পেজে যান:** অ্যাড্রেস বারে `chrome://extensions/` লিখে এন্টার দিন।
৪. **ডেভেলপার মোড অন করুন:** ডানদিকের ওপরের কোণায় থাকা **Developer mode** অন করুন।
৫. **ফোল্ডার লোড করুন:** **Load unpacked** বাটনে ক্লিক করে আপনার ফাইলগুলো রাখা ফোল্ডারটি সিলেক্ট করুন।

## 📖 How to Use

১. ফেসবুকে লগ-ইন থাকা অবস্থায় এই লিঙ্কে যান: [Sent Friend Requests](https://www.facebook.com/friends/requests/outgoing)
২. ব্রাউজারের এক্সটেনশন বার থেকে **FB Request Tool** আইকনে ক্লিক করুন।
৩. **Start Canceling** বাটনে ক্লিক করুন।
৪. টুলটি অটোমেটিক স্ক্রল করবে এবং একটির পর একটি রিকোয়েস্ট ক্যান্সেল করবে।
৫. কাজ শেষ হলে বা থামাতে চাইলে **Stop** বাটনে ক্লিক করুন।
